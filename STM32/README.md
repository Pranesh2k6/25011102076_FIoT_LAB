# STM32 Microcontroller Experiments (CAT 8 – CAT 15)

Firmware projects configured with STM32CubeMX and built on top of the STM32 HAL drivers. Every task folder includes the CubeMX hardware definition (`*.ioc`, `.mxproject`), application and driver trees (`Core/`, `Drivers/`), project files for both Keil MDK-ARM (`MDK-ARM/`) and STM32CubeIDE (`.project`, `.cproject`), an experiment write-up in `README.md`, and a circuit diagram.
