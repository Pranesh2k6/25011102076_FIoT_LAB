# 8051 Microcontroller Experiments (CAT 2 – CAT 7)

Bare-metal Embedded C firmware targeting the AT89S52 microcontroller (clocked at 11.0592 MHz) and developed in Keil µVision. Every task directory contains a self-contained Keil project (`*.uvproj`, `STARTUP.A51`, C/H sources), a pre-built HEX image under `Objects/*.hex`, an experiment README, and a Wokwi circuit schematic.
